# 365 Молитв — Telegram Бот

Telegram-бот для ежедневных каббалистических молитв и размышлений по еврейскому календарю.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен
2. Установите зависимости:
   ```bash
   cd telegram-bot
   npm install
   ```
3. Задайте токен:
   ```bash
   export BOT_TOKEN=ваш_токен
   ```
4. Запустите:
   ```bash
   npm start
   ```

## Команды бота

- `/start` — Главное меню
- `/months` — Календарь месяцев
- `/random` — Случайная молитва
- `/bookmarks` — Мои закладки
- `/help` — Справка

## Функции

- 📅 Навигация по 12 месяцам еврейского календаря
- 📖 355 молитв с разделами «Луч света», «Мудрость дня», «Молитва»
- 🔖 Закладки (сохранение в рамках сессии бота)
- 🔀 Случайная молитва
- ⬅️➡️ Навигация между днями
